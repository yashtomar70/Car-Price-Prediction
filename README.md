# Car Price Prediction

## CodeAlpha Data Science Internship Project

This project is based on Machine Learning and focuses on predicting car selling prices using different car features and specifications.

The machine learning model is trained using car-related data and predicts car prices based on important features such as present price, fuel type, and kilometers driven.

## Objective

The main objective of this project is to understand the implementation of machine learning regression techniques for price prediction using Python.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning Algorithm

- Linear Regression

## Features of Project

- Dataset Loading
- Data Visualization
- Data Preprocessing
- Model Training
- Price Prediction
- Performance Evaluation

## Dataset Features

- Car Name
- Year
- Selling Price
- Present Price
- Kms Driven
- Fuel Type
- Selling Type
- Transmission
- Owner

## Project Outcome

The machine learning model successfully predicted car selling prices with good accuracy.

## Learning Outcome

Through this project, I learned:
- Basics of Machine Learning Regression
- Data Preprocessing Techniques
- Data Visualization
- Model Training and Prediction
- Working with datasets using Python
